Selectores Avanzados CSS

Ejemplos prácticos de los principales selectores combinados en CSS

1. Selector de Descendiente (espacio)

Selecciona todos los elementos que son descendientes del primer selector, sin importar el nivel de anidación.

/* Sintaxis: */ .descendiente ul li { ... }
  • Elemento de lista 1
  • Elemento de lista 2
    • Subelemento de lista 1
    • Subelemento de lista 2

2. Agrupación de Selectores (coma)

Permite aplicar el mismo estilo a múltiples selectores al mismo tiempo.

/* Sintaxis: */ .agrupacion h1, .agrupacion p, .agrupacion span { ... }

Este es un título dentro de la clase agrupacion

Este es un párrafo dentro de un contenedor con la clase "agrupacion"

Este es un span dentro del mismo contenedor.

3. Selector de Hijo Directo (>)

Selecciona únicamente los elementos que son hijos directos (primer nivel).

/* Sintaxis: */ .hijo > div, .hijo > p, .hijo > span { ... }
Este es un div hijo directo del contenedor principal.

Este es un párrafo hijo directo del contenedor principal.

Este es un span hijo directo del contenedor principal.
Otro div hijo directo que contiene:

Este párrafo NO es hijo directo (está dentro de un div)

4. Selector de Hermano Adyacente (+)

Selecciona solamente el elemento que viene inmediatamente después del primer selector.

/* Sintaxis: */ .adyacente p + span { ... } y .adyacente p + p { ... }

Párrafo 1

Párrafo 2 (hermano adyacente de otro párrafo)

Span 1 (hermano adyacente de un párrafo) Span 2 (NO es hermano adyacente de un párrafo)

5. Selector General de Hermanos (~)

Selecciona todos los elementos que son hermanos posteriores al primer selector.

/* Sintaxis: */ .general-hermanos h2 ~ p { ... }

Encabezado 1

Párrafo 1 (afectado, hermano de h2)

Párrafo 2 (afectado, hermano de h2)

Encabezado 2

Párrafo 3 (afectado, hermano de h2)

Párrafo 4 (afectado, hermano de h2)

¡Este encabezado está fuera del ejemplo anterior!

Este párrafo NO es afectado por el selector general de hermanos

6. Pseudoclases

Seleccionan elementos en estados específicos como hover, active, focus, etc.

/* Sintaxis: */ .pseudo-class:hover { ... }
